## [FMA.M.003] Роли и инструментарий: замерщик / проектировщик / дизайнер-конструктор (SoTA-сверка по G.2)

### Definition

Проверка по реальным источникам (не по догадке), какими инструментами сейчас пользуются три роли на пути от замера помещения до готовой мебели - замерщик, проектировщик, дизайнер-конструктор. Главная находка - для маленькой мастерской это не три разных программы, а одна с разными этапами работы внутри неё.

### Замерщик - физические инструменты + опциональное ПО сканирования

Уже закрыто в этом Паке практически: лазерный дальномер (куплен, `Bosch GLM 50-27 CG`), электронный уровень, при необходимости угломер - см. [WP-36](../../DS-strategy/inbox/WP-36/WP-36.md), случай 2.

**Дополнительно найдено по SoTA (01.08.2026), не куплено, для сведения на будущее:** профессиональные услуги 3D-обмера помещений лазерным сканером (структурированный свет/лазер, точность до 1 мм) существуют как отдельный рыночный сегмент - используются в дизайне интерьеров, мебельном производстве на заказ, кадастровых работах (источник - `obmery-zamery.ru`, `disto-leica.ru`). Также существуют мобильные приложения на основе LIDAR-сканера смартфона (например «Сканер Лидар - Рулетка Линейка», iOS). **Честная оговорка:** для одной мастерской и метода трёх точек это избыточно - дальномер + уровень полностью закрывают задачу; сканер помещения - апгрейд для будущего, не для этого рабочего продукта.

### Проектировщик и дизайнер-конструктор - НЕ два инструмента, один

**Главная находка, меняющая формулировку вопроса.** Источник (`dtf.ru/software/5035106-bazis-mebelshchik...`): *«Для небольшой мастерской БАЗИС-Мебельщик становится рабочей средой, где один специалист совмещает функции дизайнера, конструктора и технолога».* Это прямо про случай пилота (Датум Мебель, малая мастерская) - не нужно заводить отдельную программу под каждую роль, весь путь от эскиза до чертежа идёт в уже установленном и разобранном в этом Паке Базис-Мебельщике (см. [FMA.M.001](FMA.M.001.md), [FMA.M.002](FMA.M.002.md)).

**Рынок аналогов (для полноты картины, не для замены).** По нескольким независимым источникам (`inner.su`, `stavros.ru`, `meb-expo.ru`) на российском рынке сложилась пятёрка систем того же класса: `Базис-Мебельщик`, `К3-Мебель`, `PRO100`, `bCAD Мебель`, `Woody`. `PRO100` отмечается как более простой вход для новичков (богатая библиотека готовых моделей), `Woody` - бесплатная, но устаревшая, `К3-Мебель` - прямой конкурент Базиса того же класса точности. **Вывод:** менять систему смысла нет - Базис уже выбран, уже есть накопленное знание в этом Паке, конкуренты не дают ничего принципиально нового для задачи пилота.

### Дизайнер-конструктор - специализированные модули той же системы (не отдельные программы, но отдельные лицензии)

Три модуля Базиса, которые относятся именно к более глубокому техническому этапу работы (не к самому проектированию модели, а к подготовке производства):

| Модуль | Что делает | Источник |
|---|---|---|
| `БАЗИС-Раскрой` | Автоматические карты раскроя материала - экономия плиты | `dtf.ru`, подтверждено также в `BazisQuick_start.pdf` (диалог настроек упоминает выбор версии модуля) |
| `БАЗИС-ЧПУ` | Формирует пакет данных для станка с числовым программным управлением - готовые файлы для реза | `dtf.ru` |
| `БАЗИС-Смета` | Расчёт стоимости изделия (упомянут ранее в этом Паке при разборе дополнительных материалов, [FMA.M.001](FMA.M.001.md)) | `BazisQuick_start.pdf` |

**Честная оговорка про лицензии.** В официальном руководстве (`BazisQuick_start.pdf`, раздел настроек) модуль `БАЗИС-Раскрой` выбирается из списка «Не выбрано / БАЗИС-Раскрой 11 / БАЗИС-Раскрой 2025» - то есть это отдельно подключаемая часть системы, не встроенная по умолчанию бесплатно. Есть ли у пилота уже действующая лицензия на `Раскрой`/`ЧПУ`/`Смета`, или их нужно отдельно приобретать - не проверено, требует уточнения напрямую в интерфейсе Базиса или у поставщика.

**Проверено на диске (01.08.2026, без запуска программы).** В папке установки (`C:\Program Files (x86)\BazisSoft\Bazis`) физически лежат отдельные исполняемые файлы всех трёх модулей - `Raskr.exe`, `CNC.exe`, `Smeta.exe`, каждый с полным официальным руководством (`Manual/ru/Cutting.pdf`, `CNC.pdf`, `Estimate.pdf`). Руководство по Раскрою прочитано целиком - модуль полноценный, поддерживает конкретные модели станков (Altendorf, Biesse Selco, Holzma, SCM и другие), не заглушка. **Присутствие файла на диске не равно активной лицензии** - при запуске программа может потребовать код активации. Практическая проверка (не выполнена агентом - нет доступа к Windows-интерфейсу): запустить `Raskr.exe` напрямую двойным кликом и увидеть, открывается ли модуль без ошибки о лицензии.

### Практический вывод для этого Пака

Из всей связки «замерщик → проектировщик → дизайнер-конструктор» реальной закупки и освоения требует по факту только роль замерщика (физические приборы). Роли проектировщика и дизайнера-конструктора закрыты уже стоящим Базис-Мебельщиком - следующий шаг не «искать/покупать программу», а «проверить, какие модули (`Раскрой`/`ЧПУ`/`Смета`) уже подключены в имеющейся лицензии».
