## [FMA.M.002] Словарь API BAZIS-Script (по официальному разбору примера автора)

### Definition

Официальный словарь функций и объектов языка скриптов Базиса - не по чужому пересказу, а по документу автора системы `my_first_tumb_2.pdf` («Напиши себе Базис, или Моя первая тумбочка 2»), который построчно разбирает ровно тот же скрипт, что уже лежит примером на диске пилота (`Example/Моя первая тумбочка 2.js`). Название документа и название файла-примера совпадают дословно - это не «похожий пример», а официальный учебный разбор именно этого файла.

### Язык - разрешено окончательно (01.08.2026)

Первый абзац документа автора прямым текстом: *«В системе Базис появилась возможность пользователю писать свои программы и подключать их Базис-Мебельщик. Программы пишутся на языке JavaScript.»* Это самый сильный из возможных источников - не косвенный вывод (движок Node.js, расширение `*.js`, см. [FMA.M.001](FMA.M.001.md)), а прямое заявление автора системы в документе, посвящённом именно этому языку. Расхождение с ранним «Pascal-подобным» описанием сайта закрыто окончательно.

### Модель объекта - как устроен скрипт (по документу)

Скрипт живёт в «области скрипта», отдельной от «области Базис-Мебельщика» - построения не видны обычным командам программы, пока их явно не передадут. Типичный скрипт-конструктор состоит из двух функций:

1. **`MakeProperties()`** - один раз объявляет панель параметров (числа, материалы, кромки, выпадающие списки, кнопки) через объект `Action.Properties` (обычно называется `Prop` в теле скрипта).
2. **`Make()`** - строит геометрию по текущим значениям параметров, вызывается заново при КАЖДОМ изменении любого параметра пользователем (через `Prop.OnChange`).

Управление жизненным циклом - через объект `Action`:

| Метод/событие | Что делает |
|---|---|
| `Action.Continue()` | Оставить построения только в области скрипта - ждать действий пользователя (редактирование параметров, нажатие кнопок) |
| `Action.Commit()` | Передать текущие построения в Базис-Мебельщик, но НЕ завершать скрипт - можно строить дальше |
| `Action.Finish()` | Передать построения в Базис-Мебельщик И завершить скрипт |
| `Action.Cancel()` | НЕ передавать построения, завершить скрипт |
| `Action.Properties.Load(file)` / `.Save(file)` | Считать/сохранить значения параметров пользователя из/в XML-файл настроек |
| `Prop.OnChange = function(){...}` | Обработчик - вызывается при любом изменении параметра, обычно внутри пересчитывает и вызывает `Make()` |
| `DeleteNewObjects()` | Не метод `Action`, отдельная функция - чистит область скрипта перед перестроением (первая строка внутри `Make()`) |

### Объявление параметров (внутри `MakeProperties()`)

| Функция | Назначение |
|---|---|
| `Prop.NewNumber('Подпись', значение_по_умолчанию)` | Числовое поле. **Важно:** возвращает не число, а объект - реальное значение в `.Value` (`Dl.Value`, не `Dl`) |
| `Prop.NewGroup('Название')` | Группа параметров (сворачиваемый раздел в окне свойств) |
| `<группа>.NewMaterial('Подпись')` | Выбор материала из базы |
| `<группа>.NewButt('Подпись')` | Выбор материала кромки |
| `<группа>.NewFurniture('Подпись')` | Выбор фурнитуры (петля, ручка и т.п.) через стандартный диалог |
| `<группа>.NewSelector('Подпись')` | Выбор произвольного файла (например, профиля фрезы) |
| `<группа>.NewCombo('Подпись', 'A\nB\nC')` | Выпадающий список, элементы через `\n`, индекс выбранного - `.ItemIndex` |
| `Prop.NewButton('Надпись')` | Кнопка на панели параметров, обработчик - `.OnClick` |
| `Prop.NewImage('Подпись', 'файл.wmf')` | Картинка-схема в окне свойств |

### Построение геометрии (внутри `Make()`)

| Функция | Назначение |
|---|---|
| `AddHorizPanel(x1, z1, x2, z2, y)` | Горизонтальная панель (координаты в глобальной системе, последний параметр - высота) |
| `AddVertPanel(y1, z1, y2, z2, x)` | Вертикальная панель |
| `AddFrontPanel(x1, y1, x2, y2, z)` | Фронтальная панель (дверь, цоколь и т.п.) |
| `<панель>.Name = 'Имя'` | Название панели в структуре модели |
| `<панель>.AddButt(материал_кромки, номер_элемента_контура)` | Облицовка кромки конкретной стороны (контур нумеруется с 0, против часовой стрелки) |
| `<панель>.AddCut('Имя')` → `.Trajectory` / `.Contour` | Паз/вырез - траектория (`AddLine`, `AddArc3`, `AddCircle`, `RoundingEx` для сопряжений) и сечение (`AddRectangle` или `.Load(файл_фрагмента)`) |
| `<панель>.Contour.Facet(x, y, размер)` | Фаска на углу контура ближайшем к точке (x,y) |
| `AddSymmetry(объект, точка, нормаль)` | Зеркальная копия (например, правая боковина из левой) - экономит повтор кода |
| `<панель>.Build()` | Отрисовать панель со всеми внесёнными изменениями |
| `BeginBlock('Имя')` ... `EndBlock()` | Группировка элементов в один блок (например, «Дверь» = панель + ручка) |
| `<блок>.AnimType = AnimationType.DoorLeft` | Тип анимации блока (открывание двери и т.п.) |

### Фурнитура и крепёж

| Функция | Назначение |
|---|---|
| `OpenFurniture('файл.f3d')` | Загрузить модель фурнитуры/крепежа из файла (папка скрипта, если путь не указан) |
| `<фурнитура>.Mount1(панель, x, y, z, угол)` | Установка на ОДНУ плоскость (ручка на дверь) |
| `<фурнитура>.Mount(панель1, панель2, x, y, z)` | Установка на СТЫК ДВУХ панелей (петля, эксцентрик, шкант, полкодержатель) - порядок панелей влияет на ориентацию (например, какая сторона петли на какой панели) |

### Служебные функции

`NewPoint(x,y)`, `NewVector(x,y,z)` - геометрические примитивы. `system.fileExists(путь)`, `system.askFileName(расширение)` - проверка файла / диалог выбора файла. `switch(...ItemIndex){case 0: ... break;}` - типовой паттерн ветвления по выбору пользователя в выпадающем списке.

### Практический смысл для этого Пака

Для случая 3 (мост Перфолента ↔ Базис-скрипт, [WP-36](../../DS-strategy/inbox/WP-36/WP-36.md)) этот словарь даёт точный список мест текстовой подстановки - Перфолента не обязана «понимать» язык целиком, достаточно подставлять числа замера в аргументы уже знакомых функций (`AddHorizPanel`, `Prop.NewNumber` со значением по умолчанию и т.п.) внутри готового шаблона скрипта, не порождая произвольный JavaScript с нуля.
