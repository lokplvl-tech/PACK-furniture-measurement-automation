## [FMA.M.005] CGUS - таблица допустимых продолжений (узор → приём кода → проверки → граница)

### Definition

Формальная структура допустимых продолжений (`CGUS`, по критерию семинара 3 §13 FPF) для генерации Базис-скрипта под конкретный узор фасада и диапазон размера. В отличие от карточек `FMA.M.001-004` (проза для человека) - эта таблица адресуется по строке, не читается целиком: агент находит строку по (узор, размер), берёт готовый приём, обязан пройти перечисленные проверки, останавливается на границе применимости, не продолжает вслепую.

### Проверка на допустимость CGUS (пять частей, по критерию семинара 3)

1. **Типизированные позиции** - см. столбцы таблицы ниже (узор / диапазон / приём / проверки / граница) - каждая строка заполняет все пять.
2. **Сигнатуры отношений** - `Узор → ПриёмКода` (один узор ссылается ровно на один проверенный приём или явно «не построено»), `Узор → Проверки[]` (список, не одна проверка).
3. **Ограничения (guards)** - см. столбец «Обязательные проверки», каждая ссылается на конкретную карточку `FMA.GRD.*`.
4. **Что сохраняется / теряется** - сохраняется: реальные числа из каталога, проверенный API. Теряется (сознательно, по нынешней границе): геометрия самого узора (фрезеровки) - строится не всегда, см. столбец «Граница».
5. **Границы применимости** - явно указаны в последнем столбце, не подразумеваются.

### Общие проверки (применимы ко всем строкам)

| Проверка | Источник |
|---|---|
| Высота > 1600мм - нужен корректор (не моделируется геометрией, только напоминание) | Общие характеристики каталога RS GROUP, стр.7 |
| Калёвки Тип 5/6 - только в эмали | Виды калёвок, стр.13 |
| Для верхних распашных модулей - высота 560-1200мм по нормативу (отдельно от предела самого узора) | Нормативы проектирования кухонных модулей |
