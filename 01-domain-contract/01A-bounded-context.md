# Bounded Context: Автоматизация замера в параметрическую модель мебели

## Что входит

- Устройство скриптового API Базиса (`BAZIS-Script`) - на чём строится геометрия, как задаются параметры, как подключается фурнитура.
- Мост между данными замера (метод трёх точек) и параметрами, которые нужно подставить в такой скрипт.
- Роль Перфоленты как оркестратора - генерирует/заполняет скрипт данными, не заменяет сам Базис.
- Вопрос источника истины (сам скрипт как параметрическая функция vs готовая построенная модель).

## Что не входит

- Сам метод P2W (`FE.M.001`) целиком - только его позиция 1 (замер, Claim Scope) как источник данных.
- Общее устройство Перфоленты - см. `PACK-perfolenta-development`.
- Конкретный выбор измерительного инструмента/протокола - открытый вопрос, не решён в этом Pack (см. `05-failure-modes` / открытые вопросы).

## Ключевые термины

| Термин | Расшифровка |
|---|---|
| `BAZIS-Script` | Собственный скриптовый интерфейс САПР «Базис» для параметрического построения мебели |
| Метод трёх точек | Способ замера помещения по трём опорным точкам - определяет геометрию и отклонения стен/пола от идеала |
| Параметрический скрипт | Программа, которая строит модель по входным числам (размеры, материалы), не готовая статичная модель |
| `AddHorizPanel`/`AddVertPanel`/`AddFrontPanel` | Функции API Базиса для размещения панелей корпуса мебели |
| `OpenFurniture`/`.Mount()` | Функции подключения и позиционирования фурнитуры (петли, полкодержатели, эксцентрики) на панели |
